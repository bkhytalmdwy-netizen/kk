# مدارس فجر الاتحاد الحديثة – مشروع تصميم مواقع الويب

**تصميم وتنفيذ وبرمجة: بخيت**

هذه النسخة مطوّرة لتطبيق متطلبات مشروع تصميم مواقع الويب، وتضم واجهات متعددة داخل الموقع: لوحة التحكم، الطلاب، المعلمون، الصفوف والفصول، الحضور والغياب، الدرجات، الجدول، الإعلانات، حسابات المعلمين، حسابات أولياء الأمور، وتواصل معنا.


## مطابقة متطلبات مشروع تصميم مواقع الويب
- تنظيم ملفات المشروع وفصل ملفات HTML وCSS وJavaScript والصور.
- استخدام عناصر HTML الدلالية مثل header وnav وmain وsection وfooter.
- أكثر من خمس واجهات/صفحات داخل الموقع، ومنها صفحة تواصل معنا.
- واجهات تسجيل الدخول وإنشاء حسابات المعلمين وأولياء الأمور مع تحقق HTML من الحقول.
- معرض صور متحرك باستخدام Bootstrap Carousel.
- استخدام Bootstrap وFont Awesome.
- استخدام CSS Grid وFlexbox وMedia Queries للتجاوب مع الشاشات المختلفة.
- بيانات التواصل وأيقونات Font Awesome في صفحة «تواصل معنا».

**ملاحظة:** تم إيقاف ميزة «فجر AI» مؤقتاً بناءً على طلب صاحب المشروع، ويمكن إضافتها لاحقاً. هذه النسخة حالياً واجهة موقع ثابتة ويمكن نشرها على استضافة صفحات ثابتة مثل Render أو Netlify.

## التشغيل على الكمبيوتر
1. فك ضغط الملف.
2. افتح مجلد المشروع.
3. شغّل `index.html` بالنقر المزدوج. ولأفضل دعم للتثبيت والعمل دون اتصال، شغّله عبر خادم محلي:
   - ثبّت Node.js.
   - افتح الطرفية داخل المجلد ونفّذ: `npx serve .`
   - افتح العنوان الذي يظهر، غالباً `http://localhost:3000`.

## الدخول التجريبي
- اسم المستخدم: `admin`
- كلمة المرور: `1234`

## تشغيله على هاتف أندرويد
- ارفع المجلد إلى استضافة تدعم HTTPS، أو شغّله على شبكة محلية للتجربة.
- افتح رابط الموقع في Chrome على الهاتف.
- من قائمة Chrome اختر «إضافة إلى الشاشة الرئيسية» أو «تثبيت التطبيق» إن ظهر الخيار.
- هذه نسخة PWA، أي تطبيق ويب قابل للتثبيت. ليست APK أصلية.

## تحويله إلى APK باستخدام Capacitor
1. ثبّت Node.js وAndroid Studio على الكمبيوتر.
2. داخل مجلد المشروع نفّذ:
   `npm init -y`
   `npm install @capacitor/core @capacitor/cli`
   `npm install @capacitor/android`
3. نفّذ:
   `npx cap init "مدارس فجر الاتحاد الحديثة" "com.amal.school" --web-dir .`
   `npx cap add android`
   `npx cap open android`
4. من Android Studio اختر Build > Build Bundle(s) / APK(s) > Build APK(s).

## ملاحظات مهمة
- هذه نسخة واجهة تشغيلية أولية. تحفظ السجلات محلياً في المتصفح عبر localStorage.
- بيانات الدخول التجريبية ليست حماية حقيقية، ولا توجد قاعدة بيانات مركزية أو مزامنة بين الأجهزة.
- لا تستخدم بيانات طلاب حقيقية أو حساسة في هذه النسخة.
- للاستخدام الفعلي في مدرسة، يلزم تطوير خادم خلفي وقاعدة بيانات (مثل PHP/MySQL أو Node.js/PostgreSQL)، وتسجيل دخول آمن بصلاحيات للمدير والمعلم والطالب وولي الأمر، ونسخ احتياطي وحماية للبيانات.
- الخط العربي يستدعي خط Cairo من الإنترنت؛ إذا لم يتوفر الإنترنت سيستخدم المتصفح خطاً بديلاً.

## حسابات المعلمين (نسخة تجريبية)
- المدير: `admin` وكلمة المرور `1234`.
- سجّل دخول المدير، ثم افتح «حسابات المستخدمين» وأنشئ حساباً لكل معلم.
- اسم المستخدم لا يقل عن 4 أحرف، وكلمة المرور لا تقل عن 6 أحرف.
- المعلم يستطيع الوصول إلى لوحة التحكم والطلاب والحضور والدرجات والجدول فقط.
- يستطيع المدير إنشاء الحسابات وإيقافها وحذفها.

**تنبيه أمني مهم:** هذه الصلاحيات والحسابات في النسخة الحالية تُدار داخل المتصفح (`localStorage`) وهي للتجربة فقط، وليست حماية آمنة للاستخدام الحقيقي أو لحفظ بيانات الطلاب. قبل الاستخدام الفعلي يجب نقل الحسابات وكلمات المرور إلى خادم وقاعدة بيانات، وتخزين كلمات المرور بصورة مشفّرة تجزئياً (hash) وتطبيق صلاحيات على الخادم.

## بوابة ولي الأمر (نسخة تجريبية)
- سجّل الدخول كمدير، ثم افتح «حسابات أولياء الأمور».
- اضغط «إنشاء حساب ولي أمر»، وأدخل اسم ولي الأمر ورقم الطالب واسم المستخدم وكلمة المرور.
- بعد تسجيل الدخول، يرى ولي الأمر ملف الطالب المرتبط فقط، ودرجاته وسجل حضوره وغيابه.
- يجب أن تكون أسماء الطلاب في سجلات الدرجات والحضور مطابقة لاسم الطالب المسجل في بيانات الطلاب.

**تنبيه:** حسابات أولياء الأمور والبيانات في هذه النسخة محفوظة محلياً داخل المتصفح لأغراض العرض والتجربة فقط. لا تستخدمها لحفظ بيانات مدرسية حقيقية قبل بناء خادم آمن وقاعدة بيانات مركزية وصلاحيات مفروضة من الخادم.

## تنبيهات أولياء الأمور (نسخة تجريبية)
- عند تسجيل حالة «غائب» لطالب، يُنشأ تنبيه في بوابة ولي الأمر المرتبط بذلك الطالب.
- عند إضافة درجة جديدة، يظهر تنبيه في بوابة ولي الأمر يتضمن المادة والفصل والدرجة.
- تظهر التنبيهات داخل حساب ولي الأمر عند تسجيل الدخول.
- يجب أن يكون اسم الطالب في سجل الحضور أو الدرجات مطابقاً تماماً لاسمه في سجل الطلاب.

**حدود النسخة الحالية:** هذه تنبيهات داخل الموقع ومحفوظة محلياً في المتصفح، وليست رسائل SMS أو إشعارات فورية تصل للهاتف عند إغلاق الموقع. لإرسال تنبيهات حقيقية عن بُعد نحتاج خادماً وقاعدة بيانات وخدمة إشعارات مثل Firebase Cloud Messaging أو بوابة رسائل.
